本版本已通过下述本机验收：**1,064 项测试通过、1 项因文件系统限制跳过；六组合成程序案例通过；真实 Qwen 卡料/正常两个案例的诊断与独立报告通过；Chrome 26 个检查组通过、0 失败**。真实 Qwen 未执行另外四个案例，不能写成真实模型六例通过。下列结果区分测试提供器、真实推理器和真实语言模型，不将它们互相替代。来源均为本工程原创合成数据，不是企业设备或客户现场验证。

- 知识：49 项真实 HermiT 测试通过、无跳过；包含分类推导、重载、命名类不可满足、不一致、版本与人工发布。HermiT 只验证声明的本体逻辑，不证明工业阈值正确。
- 时序：115 项测试通过，真实计算统计值、差值及质量/覆盖/时效条件；范围和权限隔离。
- 存储与契约：56 项测试通过，包含内容寻址制品、并发原子写入、篡改检测、严格类型、权限及未知调用使用量契约。
- 独立报告：56 项测试通过，包含终态只读、幂等、失败隔离和精确 hash 审签。模型草稿仍是不可信内容。
- 程序闭环最终第四轮：真实 HermiT + **明确 SyntheticProvider**，六种合成案例通过，5.992 秒。四个正例通过冻结诊断；missing / conflicting 必须分别以 `missing_signals` / `conflicting_signals` 升级，校验具体 Evidence 见证和完整引用信号集合，拒绝把模型失败、预算耗尽或未知调用算作负例成功。
- HTTP/CLI：214 项测试通过，包含严格 JSON、安全错误、目录边界及省略/零/正 token 对账与幂等。
- 真实浏览器最终复验：Chrome 155 独立临时 profile，真实 HermiT + SyntheticProvider，26 个检查组通过、0 失败，另有 1 项明确未测范围说明，9.31 秒。包含人工原始布尔选择、权限/状态按钮、退出后延迟响应、切任务清空旧报告、明确零用量与未知用量保守占预算。284 个自建文件扫描未发现明文测试令牌，进程和临时目录清理通过。不包括真实模型、其他浏览器和现场验证。

以上分项数目来自对应测试快照，不简单相加当总数；最终完整测试结果见后文。

## 第一轮真实 Qwen：未通过

同一公开 Qwen3-4B-Instruct-2507 Q4_K_M、显式 CPU、真实 HermiT。normal 案例在第三次模型调用后超过 300 秒累计预算，图内 341.175 秒；仅两个工具已执行。系统以 budget_exhausted 结束，没有提交诊断，jam 尚未运行。

独立耗时测量：一次调用共 69.106 秒，其中文件 hash 1.476 秒、子进程启动 1.820 秒、HTTP 推理 65.758 秒。引擎报告 1,590 个输入 token 耗时 59.560 秒，80 个输出 token 耗时 6.169 秒，输入缓存命中为 0。主要瓶颈是重复处理相同输入，不是 hash 校验。

已实现单次图运行范围内的模型进程复用和固定输入前缀缓存；保留 20 calls / 32 tools / 64,000 total tokens / 300 秒累计预算，不切换测试提供器或云模型。动态动作菜单还绑定可见的唯一信号批次和连续提交路径，减少重复 ID、无效路径造成的失败。这些改变不等于真实模型已经通过，后续闭环结果需另外记录，不能以本页前面的 SyntheticProvider 成功替代。

## 第二轮真实 Qwen：诊断通过，报告未通过

normal 在 234.480 秒内完成 10 次有效模型调用、10 次工具执行，累计 19,832 total tokens。模型依次选择意图、分批信号检查和节点展开、候选检索、最终提交；九个引用信号全部核验，无人工观察。冻结 normal 诊断通过独立预期检查。

随后独立报告调用处理含重复证据范围字段的 9,763 bytes 输入，在 180 秒 HTTP 限制下成为 unknown。原诊断保持冻结；整体验收标为失败，未继续 jam，未把部分成功称为全部通过。此后模型报告输入改为范围信息保留一次、保留全部证据 ID/状态/计算与阈值、去除重复审计元数据；正式报告仍保留完整 authoritative 内容，不改变诊断与证据。

## 第三轮真实 Qwen：正常闭环通过，人工恢复仍超预算

normal：10 次有效模型调用，211.398 秒、19,874 total tokens，诊断提交和独立报告均通过。jam：模型主动请求已声明的人工观察；显式合成回答后，恢复时新进程重新处理输入，累计到 306.690 秒，预算闸门阻止后续工具，没有错误提交。整轮标为失败，627.186 秒，包括独立报告和两案例。

为减少两次冷启动输入处理，此后缩短重复指令，仅从模型输入省去节点词法索引 terms 和空值可选字段，保留所有标签、声明谓词和已签发证据。菜单和后端仍使用完整已发布知识。未改变暂停后回收进程、300 秒预算或人工观察语义，后续结果单独验收。

## 安全复核与修复回归

独立复核发现的下列五项问题已修复并完成针对性复验，最终全量测试亦通过：

1. 模型改写人工问题可能颠倒真假含义：改由已发布条件生成确定性问题，用户明确选择原始观察事实，Evidence 保存完整问题和条件。
2. 无效模型响应也消耗 token：已修复，实际 LocalProvider HTTP/解析代码配合 MockTransport 独立复现通过，16 个无效响应各 4,000 tokens 仍累计 64,000，第 17 次不发送、没有工具执行。有效 usage 在无效结构/动作中仍保留；未知使用量阻断重发；确切发送前失败记录零。不是以真实模型制造 16 次错误来测试。
3. 当前节点的快照/事务等待等预检耗时不能遗漏：使用节点内单调时钟，在模型、工具和提交边界重新检查。
4. 过期 worker 租约不能被人工回答/对账续期：清除过期拥有者，再写入就绪状态。
5. 工具拒绝和升级审计与 worker 检查点应在同一事务内，旧 worker 不能追加误导性执行事件。

API 还检查所有变更请求的有效 JSON 对象、重复字段、非有限数、大小、同源和内容类型；异常响应不回显内部内容且保留安全响应头。CLI 新目录初始化拒绝悬空符号链接。
